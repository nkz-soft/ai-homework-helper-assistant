# Source Attribution (Draft)

All external content must be cited. Do not paste large verbatim excerpts.

## Wikipedia

- License: CC BY-SA 4.0.
- Cite the page title and URL.
- Include access date when possible.

Example citation:

```
Wikipedia: "Difference of two squares", https://en.wikipedia.org/..., accessed 2026-01-01, CC BY-SA 4.0
```

## StackOverflow

- License: CC BY-SA 4.0.
- Cite the question title, author, and URL.
- If using an answer, cite the answer author when available.

Example citation:

```
StackOverflow: "How to factor x^2 - 9?", https://stackoverflow.com/q/..., author: Jane Doe, CC BY-SA 4.0
```

## Textbooks (optional MCP)

- Use the textbook's specified license and citation format.
- If no license is available, do not surface the content in the final answer.

## Rules of use

- No long verbatim excerpts; prefer short supporting snippets.
- Every claim derived from external sources must map to a citation entry.
- If citations are missing, degrade the answer or request clarification.
