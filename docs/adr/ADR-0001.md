# ADR-0001: Use LangGraph + MCP for Orchestration

Date: 2026-01-01
Status: Accepted

## Context

The assistant needs a structured workflow with retrieval, safety checks,
and citation handling. It also needs reliable integrations with external
knowledge sources (Wikipedia, StackOverflow, optional textbooks).

## Decision

Use LangGraph for workflow orchestration and MCP servers for retrieval tools.

## Consequences

### Positive

- Clear, explicit steps for classification, retrieval, safety, and synthesis.
- MCP allowlist and tool budgets can be enforced centrally.
- Integrations remain config-driven and replaceable.

### Negative

- Additional operational complexity (MCP server management).
- More moving parts to test and monitor.
