# Contributing

Thanks for your interest in improving this project.

## Quick start

1. Check `docs/tasks/` for the current work items.
2. Open an issue before starting larger changes.
3. Keep changes focused and small where possible.

## Development notes

- This repository is a scaffold; there may be no runnable app yet.
- Place new Python packages under `src/` and include `__init__.py`.
- Update or add docs in `docs/` as you make architectural decisions.

## Pull requests

- Provide a clear description of what changed and why.
- Add or update tests when a feature becomes runnable.
- Follow the existing folder structure and naming conventions.

## Code of Conduct

By participating, you agree to follow the `CODE_OF_CONDUCT.md`.
